# Dr. Bio Design System & UI/UX Guidelines

## 1. Interface Style & Aesthetics
- **Card Containers:** Soft inset shadow containers (`shadow-clay-card` / `dark:shadow-clay-card-dark` with `border-theme-border`).
- **Brand Buttons:** Soft inset button shadows (`shadow-clay-btn`) with medical plain red accents (`bg-red-600` / `hover:bg-red-700`).

## 2. Color Palette
- **Primary Brand Color (Vivid Pure Red / Düz Kırmızı):** Vibrant medical red (`red-600` / `#dc2626` / `red-700` / `#b91c1c`). Used for brand identity, active tab states, key CTAs, logo, and primary action buttons.
- **Backgrounds & Surfaces:** Cool clean white (`#ffffff` / `#f8fafc` / `slate-50`) and cool dark slate tones (`#0f172a` / `#1e293b`). Banners use bright plain red gradients (`from-red-600 via-red-700 to-red-900`).
- **Typography & Neutral Colors:** Cool slate grays (`slate-800` / `slate-700` / `slate-400`).
- **Status Badges & Functional Red:**
  - **Critical / High Risk Values:** Crisp medical red (`red-600`, `bg-red-100 text-red-700`).
  - **Required Fields & Errors:** Red accents (`text-red-500`, `bg-red-50 border-red-200 text-red-700`).
  - **Normal Values:** Emerald green (`emerald-500` / `emerald-600`).
  - **Warnings / Out-of-reference Values:** Sky blue (`sky-600`) or Amber (`amber-500`).
